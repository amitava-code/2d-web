# AMI ✨

A dark, editorial-style landing page with smooth scroll-triggered animations, a marquee gallery, and a bold hover-driven footer.

## Preview

> Minimal. Moody. Motion-heavy.

## Features

- 🎬 **Animated hero** — big oversized typography that slides in on load
- 🖼️ **Hover-reveal gallery list** — numbered rows that reveal images and shift color on hover
- 🔁 **Infinite marquee** — auto-scrolling image strip
- 🦶 **Interactive footer** — grayscale images that saturate on hover, giant name that turns red

## Tech Stack

- HTML5
- CSS3 (custom animations, flexbox, `@keyframes`)
- Google Fonts — [Lato](https://fonts.google.com/specimen/Lato) & Google Sans

## Structure

```
.
├── index.html   # markup
└── style.css    # styling & animations
```

## Sections

| Section | Description |
|---|---|
| `.landing-page` | Hero with nav + big animated title + image |
| `.list-page` | Numbered index list with hover image reveals |
| `.marquee-section` | Infinite scrolling image track |
| `footer` | Two-column showcase + oversized name |

## Run it

Just open `index.html` in your browser — no build step needed.

```bash
open index.html
```
